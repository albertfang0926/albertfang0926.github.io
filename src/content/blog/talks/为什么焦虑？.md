最近刷朋友圈，看着别人的美好生活心中不免有些羡慕。其实这是我很多时候都会有的消
极想法，觉得过去的决定是错的，影响了现在的生活。当然前提是我对现在自己的情况并
不满意。于是我将这种想法告诉了GPT：

> 高考的时候家里的人都想让我读师范或者医学专业，但是我并不想。现在看有的同学
> 到了老师/医生反而开始羡慕他们了，觉得他们工作稳定。我时常会项目别人，羡慕
> 别人读了博士，羡慕别人参与了有影响力的github项目，羡慕别人去了一家好
> 公司......总是这样，可能是我对自己期望过高，但是自己的努力和成就匹配不上自己
> 的这份野心吧

**GPT的回答缓解了我部分焦虑的情绪。**

你描述的这种状态，我觉得不太像单纯的“对自己期望过高”，更像是**你一直在拿别人已经
确定的结果，去对比自己正在经历的过程**。而且你羡慕的东西其实很有规律：

* 同学当老师/医生 → 羡慕他们的**稳定**
* 别人读博士 → 羡慕他们的**学历和专业积累**
* 别人做有影响力的 GitHub 项目 → 羡慕他们的**技术影响力**
* 别人进好公司 → 羡慕他们的**平台**
* 看到别人某个阶段比自己好 → 开始怀疑自己当初是不是选错了

这里面有一个很重要的现象：

**你似乎不是单纯羡慕“别人拥有的东西”，而是在不断寻找一个“如果当初我走另一条路，现在是不是会更好”的答案。**

但这个问题实际上没有答案。

---

## 你真正痛苦的地方，可能不是“我不够优秀”

而是：

> **我知道自己想要很多东西，但我又没有一个明确的标准告诉自己：做到什么程度，我才算满意。**

这两件事情叠在一起，就特别容易产生挫败感。比如你现在是做前端/WebGIS的。假设你今年进入一家不
错的公司，你可能会开心一阵子。然后你会看到：“这个人进了大厂。”于是觉得自己公司还不够好。等你
进了大厂，又会看到：“这个人已经是技术负责人了。”然后觉得自己技术深度不够。再往后：“这个人博士
毕业了”，“这个人开源项目几万 Star。”，“这个人自己创业了。”，“这个人已经年薪百万了。”于是又开
始怀疑：**“是不是我其实一直都没有走对？”** 如果这个机制不改变，那么你取得什么成就，都很难真正
获得满足。

---

## 还有一个特别容易被忽略的问题

你羡慕老师、医生，是因为他们**稳定**。但如果你真的回到高中，让你重新选择一次：“现在给你一个机会，
你可以直接去学医学，毕业之后成为医生。”你真的愿意吗？你可能仍然不愿意。因为你当时不喜欢医学，所
以才没有选择它。现在你看到的是医生职业已经兑现出来的那一部分：**稳定、职业身份、社会认可、明确的
发展路径。** 但你没有同时看到：学习周期、规培、值班、工作压力、职业责任、长期投入等等。同样，你看
到博士的时候看到的是：“博士学历 + 专业积累 + 学术身份”。但你没有看到别人读博期间经历的几年时间、
论文压力、科研不确定性。看到 GitHub 大项目，你看到的是：“Star、影响力、技术成就”但你看不到作者可
能投入的数千小时。这叫一个很典型的**结果偏差**。你在拿别人的“结果截图”，和自己的“后台日志”比较。

---

## 但我反而觉得，你现在这种“不甘心”也有价值

因为从你过去一直关注的问题来看，你其实并不是一个完全没有目标的人。你一直在折腾：**Vue → WebGIS →
Cesium → Three.js → GIS 后端 → Docker → AI Coding → Agent → MCP → AI 应用。**这些东西其实能
看出一个特点：**你对“把技术做出来”这件事有比较强的兴趣。**所以我不建议你简单告诉自己：“不要焦虑，
知足常乐”。这句话解决不了你的问题。因为你可能确实有野心。真正需要解决的是：

> 如何让自己的野心从“羡慕别人”变成“建设自己的路线”。

---

## 我建议你把“羡慕”拆成三个问题

以后再看到一个人让你羡慕的时候，不要马上问：“为什么他可以，我不行？”而问：

* **我到底羡慕他的什么？** 比如：“我羡慕他读博士。”继续拆：是羡慕博士学历？
是羡慕他专业领域的深度？是羡慕他拥有一个明确的研究方向？还是羡慕他身上那种
“我在某个领域深耕了很多年”的感觉？这几个东西完全不是一回事。

* **这个东西我真的想要吗？** 比如：你说羡慕 GitHub 大项目。可能你真正想要
的并不是：“我要一个 10 万 Star 的项目。”而是：**“我希望自己做出来的东西有
人使用，并且能够证明我的技术能力。”** 那你的目标就可以变成：做一个真正解决
WebGIS/三维 GIS 问题的开源项目。这就从“羡慕别人”变成了一个具体目标。

* **如果真的想要，我愿意付出什么？** 这是最重要的问题。因为**野心真正开始变
成能力，是从接受代价开始的。**比如：你羡慕博士。那么你要接受：3～5 年甚至更
长时间的学习和科研投入。你羡慕大厂。那么你要接受：系统准备算法、计算机基础、
工程能力、项目经历和面试。你羡慕 GitHub 项目。那么你要接受：一两年持续维护
一个项目，写文档、修 Bug、处理 Issue，而不是只写一个 Demo。你羡慕技术负责人。
那么你要接受：不只是写代码，还要承担架构、沟通、项目推进、培养新人和技术决策。
**当你愿意接受代价之后，“羡慕”才真正具有行动价值。**

---

## 还有一个我觉得你现在尤其需要建立的东西：自己的“评价体系”

你现在很容易用：“别人有什么 → 我没有 → 我落后了”。来评价自己。但这个体系几乎
一定会让人痛苦。因为世界上永远存在一个人在某个维度超过你。你应该慢慢建立另外一
套评价：

> 我的能力曲线是不是在上升？例如：2024，Vue / WebGIS 基础开发；2025，Vue3 +
> Cesium + Three.js + GIS 数据处理；2026，工程化 + GIS 平台 + AI Coding + Agent。
> 下一阶段，真正把 **WebGIS + AI Agent** 做成一个完整系统这样你比较的是：**现在的我
> vs 过去的我**而不是：**我的人生 vs 别人的人生**

---

## 而且你现在其实处于一个非常容易产生这种感觉的年龄阶段

三十岁左右，人会逐渐发现：**“人生不是只有一条标准答案。”** 高中时候很简单：高考 → 好大学 →
好专业 → 好工作。但工作几年之后，你突然发现：有人做医生，有人做老师，有人读博士，有人进大
厂，有人创业，有人做公务员，有人移民，有人回老家。然后你会突然意识到：**原来人生可以有这么多条路线。**
这时候很容易产生一种错觉：“是不是别人都选对了，而我选错了？”其实不是。只是你第一次真正看见了**路径依赖**。

---

## 最后我想送你一句话

你现在真正需要解决的，也许不是：**“我为什么没有成为那些让我羡慕的人？”** 而是：**“如果不再考虑别人，我到底希望自己五年以后成为一个什么样的人？”**
然后再倒推：**五年目标 → 三年能力 → 一年成果 → 这个月行动。** 你甚至可以允许自己有野心。**野心本身不是问题。**
真正让人痛苦的是：野心很大，但没有把它转换成具体路径，于是每天只能通过羡慕别人
来提醒自己“我还没有成为那个理想中的人”。你不一定需要降低自己的期待。你更需要做
的是：**把“我想成为一个厉害的人”，变成几个可以被完成、被验证、被积累的具体目标。**
到那个时候，你看到一个博士、一个医生、一个大厂员工、一个 GitHub 大佬时，可能依
然会羡慕——但这种羡慕不会再变成对自己的否定，而会变成： **“这个东西不错。也许我也可以去试试。”**
这两种心理状态，差别其实非常大。
